# Hackathon models

Prototypes built at Départ de Sentier hackathons, one folder per model:

```
hackathon/<model-name>/     lowercase, dashes, no spaces
```

Each folder carries its own `README.md` (what it computes, who built it,
what it is based on, which AI tool was used and how the output was checked,
source and licence of every data file, how to run it) and follows the
rules in the [root README](../README.md).

Hackathon folders are working prototypes, not curated releases: a merge
here means "clean enough to run and correctly licensed", not "endorsed as
a platform component". Proposals that touch the Sentier data repos
(schemas, new tables, importers) are discussed in those repos' issues
before anything moves.
